# The Homeland: VP Economy Simulator

## Overview
This is a simple Python simulation designed to model the economy of merit within "The Homeland: Forging the Republic". It demonstrates how Valor Points (VP) are earned through Quests and Raids, and how they decay over time due to inactivity.

## The Core Concept
The simulation highlights a key lesson from the Republic's onboarding:
*"Why consistent contribution matters more than raw presence."*

By modeling both earning and decay, this script shows that a member who consistently contributes small amounts will eventually surpass a member who earned a large amount once but then went inactive.

## Features
*   **Earn VP:** Simulates completing Quests and Raids.
*   **Decay Mechanism:** Simulates the loss of VP over time when a member is inactive.
*   **Status Tracking:** Keeps track of each member's current VP and activity status.
